AutoXDM – Privacy Policy

Last Updated: {{date}}

AutoXDM (“we”, “our”, or “us”) is a browser extension designed to help users automate sending direct messages (DMs) on X/Twitter. We take privacy seriously. This Privacy Policy explains what data we collect, how we use it, and how we protect it.

1. What Information We Collect

AutoXDM does not collect, store, transmit, or sell any personal data.

We do NOT collect:

  • Names
  • Emails
  • Passwords
  • Phone numbers
  • IP addresses
  • Payment information
  • Messages or DM content
  • Browsing history
  • Website activity
  • Analytics
  • Cookies
  • Social media data
  • Any personally identifiable information

All actions performed by AutoXDM occur entirely on the user’s device, within their own browser, and under their direct control.

2. Local Storage Only

AutoXDM stores certain settings locally on your device to improve usability.

These may include:

  • DM message templates
  • Delay settings
  • Campaign progress
  • User interface preferences

This information never leaves your device and is never transmitted to AutoXDM servers or third parties.

3. Permissions Used

AutoXDM requires certain Chrome extension permissions to function.

Here’s how we use them:

  • cookies
    Used only to verify that the user is logged into X/Twitter while sending DMs. No cookie data is collected or transmitted.
  • tabs
    Used to identify the active X/Twitter tab where the user initiates automation. Not used to track browsing or access other sites.
  • host permissions (x.com, twitter.com)
    Required to automate actions only on the X/Twitter interface. AutoXDM does not access or interact with any other sites.
  • storage / unlimitedStorage
    Used only to save user preferences and templates locally. No external storage is used.
  • remote code
    Used only to fetch configuration or template updates from autoxdm.com. No third-party remote code is executed.

4. No Data Sharing or Selling

AutoXDM:

  • does NOT sell user data
  • does NOT transfer user data
  • does NOT use data for advertising
  • does NOT send data to any servers
  • does NOT share data with third parties

Because we do not collect data, there is nothing to sell or share.

5. Single Purpose

AutoXDM has one single purpose: To automate the process of sending user-authorized direct messages on X/Twitter. We do not use any permissions for purposes outside this single function.

6. Third-Party Services

AutoXDM does not use:

  • Google Analytics
  • Advertising networks
  • Tracking pixels
  • Social media APIs
  • Third-party data processors

7. Security

Because no data is collected or transmitted, the risk of exposure is extremely low. However, the extension still follows standard security best practices to prevent unauthorized behavior.
